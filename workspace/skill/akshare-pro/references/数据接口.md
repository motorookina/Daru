# 1.期货主力连续 futures_main_sina

## 接口概述
- **接口名称**：`futures_main_sina`（AKShare 库）
- **目标地址**：https://vip.stock.finance.sina.com.cn/quotes_service/view/qihuohangqing.html#titlePos_0
- **描述**：获取新浪财经‑期货主力连续合约的日频历史数据
- **限量**：单次请求仅返回**单个品种**的主力连续合约历史数据

---

## 输入参数

| 参数名 | 类型 | 描述 |
|--------|------|------|
| `symbol` | str | 品种代码，如 `"IF0"`。需参考下方**品种一览表**，也可通过 `ak.futures_display_main_sina()` 获取 |
| `start_date` | str | 开始日期，格式 `"19900101"` |
| `end_date` | str | 结束日期，格式 `"22220101"`（支持远期货期） |

# 2.中债综合指数 bond_new_composite_index_cbond

## 接口概述
- **接口名称**：`bond_new_composite_index_cbond`（AKShare）
- **目标地址**：`https://yield.chinabond.com.cn/cbweb-mn/indices/single_index_query`
- **描述**：中国债券信息网 · 中债指数 · 中债指数族系 · 总指数 · 综合类指数 · 中债‑新综合指数

---

## 输入参数

| 参数名 | 类型 | 描述 |
|--------|------|------|
| `indicator` | str | 指标类型，默认 `"财富"`。可选值见下方列表 |
| `period` | str | 待偿期限分段，默认 `"总值"`。可选值见下方列表 |

### `indicator` 可选值
`全价`, `净价`, `财富`, `平均市值法久期`, `平均现金流法久期`, `平均市值法凸性`, `平均现金流法凸性`, `平均现金流法到期收益率`, `平均市值法到期收益率`, `平均基点价值`, `平均待偿期`, `平均派息率`, `指数上日总市值`, `财富指数涨跌幅`, `全价指数涨跌幅`, `净价指数涨跌幅`, `现券结算量`

### `period` 可选值
`总值`, `1年以下`, `1-3年`, `3-5年`, `5-7年`, `7-10年`, `10年以上`, `0-3个月`, `3-6个月`, `6-9个月`, `9-12个月`, `0-6个月`, `6-12个月`

---

## 输出参数

| 字段名 | 类型 | 描述 |
|--------|------|------|
| `date` | object | 交易日期 |
| `value` | float64 | 指数值（注意单位，随 `indicator` 不同而变化） |

---

## 接口示例（Python）

```python
import akshare as ak

bond_new_composite_index_cbond_df = ak.bond_new_composite_index_cbond(
    indicator="财富", 
    period="总值"
)
print(bond_new_composite_index_cbond_df)
```

# 3.国债收益率（中债）bond_china_yield

## 接口概述
- **接口名称**：`bond_china_yield`（AKShare）
- **目标地址**：`https://yield.chinabond.com.cn/cbweb-pbc-web/pbc/historyQuery?startDate=2019-02-07&endDate=2020-02-04&gjqx=0&qxId=ycqx&locale=cn_ZH`
- **描述**：中国债券信息网 · 国债及其他债券收益率曲线
- **限量**：单次返回指定日期范围内（`start_date` 到 `end_date` 需小于一年）的所有数据

---

## 输入参数

| 参数名 | 类型 | 描述 |
|--------|------|------|
| `start_date` | str | 开始日期，格式如 `"20190204"`；`start_date` 到 `end_date` 需小于一年 |
| `end_date` | str | 结束日期，格式如 `"20200204"`；`start_date` 到 `end_date` 需小于一年 |

---

## 输出参数

| 字段名 | 类型 | 描述 |
|--------|------|------|
| `曲线名称` | str | 债券收益率曲线名称（如"中债国债收益率曲线"等） |
| `日期` | object | 交易日期 |
| `3月` | float64 | 3个月期收益率 |
| `6月` | float64 | 6个月期收益率 |
| `1年` | float64 | 1年期收益率 |
| `3年` | float64 | 3年期收益率 |
| `5年` | float64 | 5年期收益率 |
| `7年` | float64 | 7年期收益率 |
| `10年` | float64 | 10年期收益率 |
| `30年` | float64 | 30年期收益率 |

---

## 接口示例（Python）

```python
import akshare as ak

bond_china_yield_df = ak.bond_china_yield(

)
```

# 4.回购利率历史 repo_rate_hist

# 5.主板市盈率 stock_market_pe_lg

## 接口概述
- **接口名称**：`stock_market_pe_lg`（AKShare）
- **目标地址**：`https://legulegu.com/stockdata/shanghaiPE`
- **描述**：乐咕乐股 · 主板市盈率
- **限量**：单次获取指定 `symbol` 的所有历史数据

---

## 输入参数

| 参数名 | 类型 | 描述 |
|--------|------|------|
| `symbol` | str | 市场名称，可选值：`"上证"`、`"深证"`、`"创业板"`、`"科创版"` |

---

## 输出参数（上证、深证、创业板）

| 字段名 | 类型 | 描述 |
|--------|------|------|
| `日期` | object | 交易日期 |
| `指数` | float64 | 对应市场指数点位 |
| `平均市盈率` | float64 | 市场平均市盈率（PE） |

---

## 接口示例（上证、深证、创业板）
